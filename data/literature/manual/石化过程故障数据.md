# 石化过程典型故障数据

## 催化裂化装置
催化剂循环量下降10% → 反应温度降低8-12°C → 转化率下降5-8% → 汽油收率降低。
再生器密相温度每升高10°C，催化剂失活速率加倍。
因果链: 待生催化剂积碳↑ → 再生烧焦不足 → 催化剂活性↓ → 转化率↓ → 产品分布偏移。
关键参数: 剂油比正常范围6-8，低于5需检查催化剂循环系统。

## 乙烯裂解炉
炉管出口温度(COT)每升高5°C，结焦速率增加30%。
炉管壁温超过设计值20°C运行100小时，管壁渗碳深度增加0.5mm。
因果链: COT偏高 → 裂解深度过大 → 二次反应加剧 → 结焦加速 → 炉管压降↑ → 运行周期缩短。
正常COT范围: 820-840°C (石脑油裂解)。

## 加氢裂化反应器
床层压降突然增大预示催化剂床层堵塞或沟流。
径向温差>15°C表明床层分布不均。
因果链: 进料杂质↑ → 催化剂床层堵塞 → 压降↑ → 偏流 → 径向温差↑ → 热点风险。
紧急: 床层压降超过设计值150%立即降负荷。

## 常减压蒸馏塔
塔顶温度每降低2°C，石脑油干点降低10°C，影响下游重整进料。
塔底温度低于正常值15°C，减压渣油中轻组分增加，减拔不彻底。
因果链: 加热炉出口温度↓ → 汽化率不足 → 分馏精度下降 → 产品馏程重叠。

## 延迟焦化
焦炭塔切换时，预热不充分导致塔壁温差>80°C，引发热应力裂纹。
泡沫层高度异常表明原料性质变化或消泡剂注入不足。
因果链: 原料残炭值↑ → 泡沫层上升 → 油气携带焦粉 → 分馏塔结焦 → 停工清焦。

## 聚丙烯装置
环管反应器密度波动>±3kg/m³，聚合物粒子形态不均。
催化剂活性每下降5%，需要提高反应温度1°C补偿。
因果链: 催化剂活性↓ → 反应温度↑补偿 → 副反应↑ → 等规度↓ → 产品质量下降。
